# Iteration 011：默认启动页面

| 属性 | 内容 |
|---|---|
| 状态 | Implemented / Verified |
| 日期 | 2026-09-09 |
| 分支 | `feat/default-startup-page` |
| 用户故事 | US-SET-005 |
| 需求 | SET-004–SET-005、SET-008 |

## 1. 目标

让用户选择 UFrame 启动后的第一工作页面，同时保证设置过程自然、首屏无中间页面闪烁，并保护详情深链和画布筛选上下文。

## 2. 交付范围

- 设置页增加“启动”区域，支持机柜一览、位置管理、机柜管理和设备资产四个一级页面。
- 选择立即保存但不离开当前设置页，下次应用启动生效。
- 默认启动页面随其他 UI 偏好保存在版本化本地存储，不进入 SQLite 或 Tauri IPC。
- 应用从无参数根路径启动时，在 React 首屏和 Browser Router 创建前替换为目标路径。
- 详情页、列表路径以及带 query 或 hash 上下文的根路径保持原地址。
- 应用启动后用户点击“机柜一览”不会再次触发启动重定向。
- 旧偏好缺少字段、字段无效或执行恢复默认时回退到机柜一览。
- 新增简体中文、英语文案和启动路径单元测试。

## 3. 明确未纳入

- 把设置页、创建页、编辑页或详情页作为默认启动页面。
- 记住退出应用前最后访问的页面。
- 根据机房、区域或设备状态动态选择启动页。
- 数据目录、备份、迁移与恢复；这些能力已确认为产品非目标。

## 4. 验证证据

- `pnpm gate`：2026-09-09 通过；文档、版本、bindings、ESLint、TypeScript、前端测试、生产构建、Rust format、Debug/Release Clippy 和 Rust 全量测试全部通过。
- React 自动化测试：覆盖四个路径映射、根路径替换、机柜一览默认不替换、详情深链及 query/hash 上下文保护、选择持久化和恢复默认。
- Tauri Debug `.app` 验证：选择设备资产后当前设置页保持不变，关闭并重新启动后首屏直接进入设备资产；随后点击机柜一览可正常进入画布。
- 本轮不修改数据库 schema、业务数据、Tauri Command 或 IPC bindings。

## 5. 结果

Iteration 011 完成 US-SET-005。启动偏好仅参与应用初始根路径解析，运行期导航继续由现有 Browser Router 控制，因此兼顾了快速进入常用页面和可恢复深链。
