## 1. 迭代目标

补齐位置、机柜和资产的独立只读详情，使用户可以从列表和机柜画布持续下钻并核对完整信息。

## 2. 实现范围

- 机房详情展示基本信息、区域数、机柜数和区域入口。
- 区域详情展示基本信息、机柜数、总 U 数和机柜入口。
- 机柜详情展示规格、位置、容量指标、额定功率、备注和当前设备列表。
- 资产详情展示完整台账字段、当前位置及机房、区域、机柜和画布入口。
- 位置、机柜、资产列表增加查看入口，画布设备侧栏增加完整详情入口。
- 复用现有只读 IPC 投影，不增加 migration 或后端 Command。

## 3. 非目标

- 不实现编辑、归档、移动、下架和历史放置记录。
- 不增加为单个实体重复读取相同字段的 IPC Command。

## 4. 验收与门禁

- Testing Library 覆盖机房/区域下钻、机柜容量和设备列表、资产完整字段与当前位置互链。
- 实际 Tauri 窗口检查列表入口、详情布局、关联跳转和画布定位。
- 功能 worktree 与 squash 后的 `main` 均执行完整 `pnpm gate`。

验收结果：

- 功能 worktree 的 `pnpm gate` 全部通过：文档与 bindings 一致性、ESLint、TypeScript、16 个 Vitest、前端构建、Rust format、Debug/Release Clippy `-D warnings` 和 9 个 Rust 测试。
- Testing Library 验证了机房到区域、区域到机柜、机柜到设备，以及资产当前位置到机房、区域和机柜的深链。
- 独立 Debug `.app` 使用隔离的应用标识和验收数据库，在 1280×800 实际 Tauri 窗口中检查了位置列表、机房详情、区域详情、机柜详情、资产详情、画布定位和画布侧栏完整详情入口。
- 机柜详情正确显示 2 台设备、已占用 3U、可用 39U 和 7% 占用率；资产详情正确显示完整网络标识与 U10–U11 当前位置。
- 验收数据只写入隔离的 QA 应用目录，不修改正式 UFrame 数据库。
