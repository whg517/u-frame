## 1. 迭代目标

把机柜一览内容区收敛为可滚动的网格画布，支持 50%–160% 缩放和机柜横向排序。排序写入 SQLite，刷新或重启后保持；设备仍通过表单上架或移动。

## 2. 实现范围

- 背景使用低对比度 CSS 网格线，并随画布缩放同步改变网格尺寸。
- 右下角提供缩小、恢复 100% 和放大控件；按住 Command 或 Control 滚轮也可缩放。
- 机柜标题作为拖动手柄，可放到目标机柜前后；左右方向键提供等价排序能力。
- `0002_rack_sort_order.sql` 为 `racks` 增加 `sort_order`，旧数据按创建时间和 ID 确定初始顺序。
- `reorder_racks` 在事务中校验空列表、重复 ID 和无效机柜，并保留筛选范围外机柜的相对顺序。
- 前端先乐观更新；IPC 保存失败时回滚并展示错误。

## 3. 非目标

- 不实现设备拖拽上架或移动。
- 不实现机柜自由二维摆放、画布平移和坐标持久化。
- 不实现缩放偏好持久化和大规模虚拟化。

## 4. 验收与门禁

- Rust 测试覆盖排序持久化、筛选子集排序和重复 ID 拒绝。
- Vitest 覆盖缩放边界、缩放控件、拖动排序、键盘排序和失败回滚。
- 浏览器检查网格、缩放边界、U 位对齐及横向滚动。
- 实际 Tauri 窗口检查多机柜缩放、拖动保存和重启后顺序。
- 功能 worktree 与 squash 后的 `main` 均执行完整 `pnpm gate`。

验收结果：

- 功能 worktree `pnpm gate` 全部通过：文档与 bindings 一致性、ESLint、TypeScript、12 个 Vitest、前端构建、Rust format、Debug/Release Clippy `-D warnings` 和 9 个 Rust 测试。
- 1280×720 浏览器视口中画布可用区域为 1040×656；80% 时背景网格为 19.2px，160% 时为 38.4px，达到上限后放大按钮禁用。
- 实际 Tauri 窗口检查了 42U、27U、18U 等多机柜、四类设备、140% 缩放、横向滚动和 U 位边界对齐。
- 拖放排序由 React 交互测试覆盖，排序事务及重启后可恢复的数据顺序由 Rust 集成测试覆盖；失败回滚和重复 ID 拒绝均已验证。
- squash 合并后的 `main` 再次通过完整 `pnpm gate`，结果与功能 worktree 一致。
