## 1. 目标

建立一个自然、可恢复的设置入口，让用户调整 UFrame 的外观和界面语言；偏好只保存在当前 Mac，不改变机房、机柜、设备或放置数据。

## 2. 交付范围

- 固定侧栏增加“设置”，路由为 `/settings`。
- 外观支持跟随系统、浅色和深色；跟随系统时监听 macOS 外观变化。
- 主题色支持中性灰、蓝色、绿色、橙色和紫色，并通过语义 token 统一影响主要操作、选中态和焦点环。
- 界面语言支持简体中文和英语，覆盖导航、列表、详情、表单、画布、校验错误及无障碍标签。
- 设置即时生效并自动写入带版本的本地偏好；应用首屏渲染前恢复。
- 损坏或未知偏好逐字段回退，不影响应用启动。
- 支持一键恢复系统外观、中性灰和简体中文默认值。

## 3. 明确未纳入

- 字体大小和界面密度。
- 默认画布缩放和默认启动页面。
- 数据目录、备份位置及跨设备同步。
- 翻译用户输入的资产名称、位置名称、厂商或型号。

- React 自动化测试：覆盖偏好容错、DOM 主题属性、即时保存、恢复默认以及语言切换后的固定导航。
