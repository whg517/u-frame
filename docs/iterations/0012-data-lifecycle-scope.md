# Iteration 012：收敛数据生命周期范围

| 属性 | 内容 |

## 1. 决策

UFrame 不提供以下面向用户的数据生命周期能力：

- 创建或管理业务数据备份。
- 在安装、设备或自定义目录之间迁移业务数据库。
- 使用备份或其他数据副本恢复、替换当前业务数据。
- 在设置中修改业务数据库存储位置。

业务 SQLite 数据库继续固定保存在 macOS 应用数据目录。Excel 导入导出仍是独立的数据交换能力，不属于备份或恢复。

## 2. 技术边界

产品范围中的“数据迁移”与内部 SQLite schema migration 不同。应用升级仍必须执行向前演进、受测试保护的 schema migration，且不得通过删除用户数据库处理版本变化；该机制不提供用户入口，也不用于跨安装搬运数据。
