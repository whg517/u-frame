# Iteration 009：默认机柜画布缩放

| 属性 | 内容 |
|---|---|
| 状态 | Implemented / Verified |
| 日期 | 2026-09-08 |
| 分支 | `feat/default-canvas-zoom` |
| 用户故事 | US-SET-003 |
| 需求 | SET-004–SET-006 |

## 1. 目标

让用户根据屏幕尺寸和常用机柜数量选择机柜一览的默认视野，同时保持当前页面临时缩放的轻量交互。

## 2. 交付范围

- 设置页增加“机柜画布”区域，提供 80%、100%、120% 和 140% 四档默认缩放。
- 默认缩放随其他 UI 偏好即时写入版本化本地存储，不进入 SQLite 或 Tauri IPC。
- 每次进入或重新进入机柜一览时从所选默认值初始化。
- 画布百分比按钮从固定重置到 100% 改为重置到用户所选默认值。
- 旧版本偏好缺少字段、字段无效或存储损坏时回退到 100%。
- 恢复默认设置同时把默认画布缩放恢复为 100%。
- 新增中文和英文界面文案及无障碍标签。

## 3. 明确未纳入

- 持久化用户在画布中的每一次临时缩放。
- 针对不同机房或区域保存不同默认缩放。
- 字体大小、界面密度和默认启动页面。
- 数据目录、备份位置及跨设备同步。

## 4. 验证证据

- `pnpm gate`：2026-09-08 通过；文档、版本、bindings、ESLint、TypeScript、前端测试、生产构建、Rust format、Debug/Release Clippy 和 Rust 全量测试全部通过。
- React 自动化测试：覆盖默认缩放选择与持久化、旧偏好回退、画布初始化、临时缩放和重置到所选默认值。
- 本轮只改变 WebView 本地偏好和前端画布状态，不修改数据库 schema、业务数据或 IPC bindings。

## 5. 结果

Iteration 009 完成 US-SET-003。默认画布缩放与既有主题、语言偏好使用同一容错存储，画布保留 50%–160% 的临时缩放范围，并把重置目标从固定 100% 改为用户所选默认值。
