## 1. 迭代目标

补齐机房、区域、机柜和设备的修改路径，并把机柜一览从单区域下拉框升级为机房、区域两级的“全部 / 多选 / 联动”筛选。

## 2. 实现范围

- 四类详情页提供编辑入口，编辑路由复用创建表单并完整回填已保存字段。
- 新增 `update_room`、`update_area`、`update_rack` 和 `update_asset` 类型化 IPC Command。
- 机柜编辑支持修改所属区域、编码、规格、总 U 数、额定功率和备注。
- 设备编辑支持修改全部台账字段；已上架设备高度改变时同步更新活动放置高度。
- 应用事务与 SQLite trigger 共同拒绝机柜缩容越界、设备高度越界或重叠，失败时保留原数据。
- 画布机房和区域筛选均支持全部与多选；区域候选项随机房选择联动，筛选状态进入 URL，可从详情深链恢复。

## 3. 非目标

- 不实现归档、设备移动、下架、搜索、审计和历史放置查询。
- 不修改机柜排序、缩放和设备上架的既有交互。

## 4. 验收与门禁

- Rust 测试覆盖四类实体更新、机柜缩容拒绝、设备高度重叠拒绝和数据库 trigger 保护。
- Testing Library 覆盖四类编辑表单回填与提交、详情编辑入口、全部与多选筛选行为。
- 功能 worktree 与 squash 后的 `main` 均执行完整 `pnpm gate`。
- 使用隔离的 QA 应用标识与数据库在实际 Tauri 窗口中检查编辑保存、筛选联动和画布结果，不修改正式 UFrame 数据。

验收结果：

- 功能 worktree 的 `pnpm gate` 已通过：文档、bindings、ESLint、TypeScript、25 个 Vitest、前端构建、Rust format、Debug Clippy、Release check 和 13 个 Rust 测试全部通过。
- 隔离的 `UFrame QA.app` 在 1280×800 实际 Tauri 窗口中显示 42U、27U 和 18U 三个机柜，画布、网格、U1 基线、设备块和筛选弹层布局正常。
- 实际验证“全部机房 / 全部区域”、单选、两个机房多选、两个区域多选，以及选择上海机房后区域候选只保留上海的服务器区和网络区。
- 机房、区域、机柜和设备编辑页均完整回填并成功保存；机柜额定功率由 8000 W 更新为 8500 W，已上架设备高度由 2U 更新为 3U 后，当前位置同步从 U10–U11 变为 U10–U12。
- QA 数据只写入 `com.whg517.uframe.qa` 的隔离应用目录，不修改正式 UFrame 数据库。
