# ADR-003：采用 Tailwind CSS 与 shadcn Base UI

| 属性 | 内容 |
|---|---|
| 状态 | Accepted |
| 日期 | 2026-09-04 |

## 背景

桌面管理工具需要可维护、可访问、支持系统深浅色模式的基础组件，同时机柜画布需要独立的轻量线框视觉语言。

## 决定

采用 Tailwind CSS 4 和 shadcn Base UI 源码组件。应用外壳与表单复用基础组件；机柜图使用业务 CSS 和纯计算函数，不使用图片或重型画布依赖。

## 后果

- 组件源码随仓库维护，可以按桌面场景调整。
- 主题跟随 macOS，不在 Iteration 001 增加持久化主题状态。
- 机柜画布保持灰阶、1px 线框、无渐变和无 3D 表达。
