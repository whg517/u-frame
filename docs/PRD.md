## 1. 产品概述

UFrame 是一个以物理位置为核心的本地机柜与设备资产管理工具。用户可以维护机房、区域、机柜以及服务器和网络设备信息，将设备放置到具体 U 位，并通过机柜画布查看设备在机柜中的分布。

产品第一阶段定位为单机资产台账，不承担监控平台、远程运维平台或完整 CMDB 的职责。

## 2. 背景与问题

服务器及网络设备资产通常分散在 Excel、在线表格或人工记录中，物理上架位置与资产字段容易出现不一致。现有表格可以描述设备属性，但难以直观回答以下问题：

- 某台设备位于哪个机房、机柜和 U 位？
- 某个机柜还剩多少连续可用 U 位？
- 移动或新增设备后是否与已有设备冲突？
- 哪些设备尚未上架、已经下线或处于维护状态？
- Excel 数据与本地台账之间有哪些新增、修改或缺失记录？

## 3. 产品目标

### 3.1 MVP 目标

- 建立机房、区域、机柜、设备和 U 位放置关系的统一数据模型。
- 提供清晰的多机柜画布，直观展示设备所在 U 位。
- 支持服务器、交换机、路由器和防火墙的新增、编辑、归档、搜索和筛选。
- 在设备上架或移动时执行越界及 U 位冲突校验。
- 支持 Excel 导入预览、差异确认和结果复核。
- 所有核心数据保存在本机应用数据目录，不依赖远程服务。

### 3.2 成功标准

- 用户能够在 3 分钟内创建机柜并完成第一台设备上架。
- 机柜画布与设备台账使用同一数据源，不存在人工维护的第二份位置数据。
- 系统不能保存越界或同一机柜内 U 位重叠的放置记录。
- Excel 导入必须先展示差异，未经确认不得覆盖正式数据。

## 4. 非目标

以下能力不进入 MVP：

- Ping、SNMP、IPMI、Redfish 等自动监控与采集。
- SSH、远程开关机、批量执行和自动化运维。
- 多用户协作、组织权限、审批流和细粒度授权。
- 与 CMDB、钉钉或其他平台实时双向同步。
- Intel Mac、Windows arm64、32 位与移动客户端。
- 网络端口、线缆、配线架和电源链路拓扑。
- 告警中心、容量预测和能耗分析。
- 数据备份、跨安装或跨目录迁移、数据恢复，以及用户自定义业务数据库位置。

## 5. 用户与使用场景

### 5.1 目标用户

- 维护少量机房、物理服务器和网络设备的运维人员。
- 需要离线管理实验室或家庭机柜的管理员。
- 负责核对设备台账与实际上架位置的资产管理员。

### 5.2 核心场景

1. 初次使用时创建机房、区域和机柜。
2. 手工新增设备并分配机柜 U 位。
3. 从 Excel 导入已有设备资产。
4. 在机柜画布中选择设备并查看详情。
5. 将设备从一个机柜移动到另一个机柜。
6. 查询某个机柜的连续空闲 U 位。
7. 将下线设备归档并释放占用的 U 位。

## 6. 信息架构

```text
机房
└── 区域
    └── 机柜
        └── U 位放置关系
            └── 设备
```

建议的一级功能入口：

- 机柜一览
- 设备资产
- 机房与区域
- 导入与导出
- 操作记录
- 系统设置

### 7.4 U 位放置

统一使用以下定义：

- `startU` 表示设备占用的最低 U 位。
- `heightU` 表示设备占用高度。
- 实际占用范围为 `[startU, startU + heightU - 1]`。
- 机柜画布顶部显示最大 U，底部显示 U1。

| 编号 | 需求 | 优先级 |
|---|---|---|
| PLC-001 | 用户可以将未上架设备放置到指定机柜和起始 U 位。 | P0 |
| PLC-002 | 用户可以移动或下架设备。 | P0 |
| PLC-003 | 放置范围不得小于 U1 或超过机柜总 U 数。 | P0 |
| PLC-004 | 同一机柜内的设备占用范围不得重叠。 | P0 |
| PLC-005 | 一台设备最多只能有一个有效放置记录。 | P0 |
| PLC-006 | 保存前必须显示设备最终占用范围。 | P0 |
| PLC-007 | 画布中的多个设备位置调整在保存前保持为草稿；确认保存时必须在同一事务中整体生效，取消或失败不得改变当前放置。 | P0 |

MVP 包含以下核心业务对象：

- 机房
- 区域

## 9. 非功能需求

### 9.1 本地优先

- MVP 不依赖远程服务器即可使用。
- 系统断网时，本地查询与保存仍立即执行，不得等待网络恢复。
- 数据库保存在操作系统的应用数据目录。
- 未经用户主动操作，不上传资产数据。

### 9.2 性能

- 500 台机柜、10,000 台设备规模下，常用列表首次展示不超过 2 秒。
- 单个区域包含 100 台机柜时，画布滚动和缩放应保持可用。
- 搜索输入后 300 毫秒内显示结果。

### 9.3 可靠性

- 核心写操作失败后不能留下部分更新的数据。
- 应用升级不能静默丢失或跳过用户数据。
- 后台数据刷新不得覆盖正在编辑的字段或用户已选择的父级对象。
- 页面加载或渲染异常时应提供可理解的提示和返回入口，不展示技术堆栈。

### 9.4 安全

- 未经用户主动选择，应用不得读取或写入业务无关的本地文件。
- 错误提示和日志不得暴露设备凭据、数据库内容或不必要的本地路径。
- MVP 不保存远程设备密码、SSH Key 或 API Token。

### 9.5 可维护性

- 机柜画布根据放置数据派生，不单独保存另一份画布位置真相。
- U 位冲突、设备移动和导入差异必须具备可重复验证的测试。

## 11. MVP 验收场景

### AC-001 创建并展示机柜

1. 创建一个 42U 机柜 A-01。
2. 在机柜中放置一台从 U19 开始、高度 4U 的设备。
3. 机柜图顶部显示 U42、底部显示 U1。
4. 设备显示在 U22 至 U19。

### AC-002 阻止 U 位冲突

1. A-01 的 U22 至 U19 已被占用。
2. 尝试在 U21 放置一台 2U 设备。
3. 系统拒绝保存并标明冲突范围。

### AC-003 移动设备

1. 将设备从 A-01 的 U22 至 U19 移动到 A-02 的 U10 至 U7。
2. A-01 原位置恢复为空闲。
3. A-02 显示新的设备位置。
4. 操作记录包含变更前后位置。

### AC-004 导入资产

1. 选择包含设备资产的 Excel 文件。
2. 系统解析并展示新增、修改、缺失和冲突项。
3. 用户确认后应用变更。
4. 系统重新读取正式数据并展示结果摘要。

### AC-005 本地数据边界

1. 业务数据库由应用固定保存在各操作系统的应用数据目录。
2. 界面不提供备份、跨安装或跨目录迁移、恢复及修改业务数据库位置的入口。
3. 应用升级所需的 SQLite schema migration 由应用内部执行，不作为用户数据迁移功能暴露。

### AC-006 查看实体详情

1. 从位置列表进入机房详情，并继续进入区域及其机柜详情。
2. 机柜详情展示总容量、已占用、可用容量、占用率和当前设备列表。
3. 从设备列表或画布侧栏进入资产详情，查看完整标识字段和当前位置。
4. 资产当前位置可以跳转到所属机房、区域和机柜，已上架资产可以在画布中定位。

### AC-007 修改实体并筛选画布

1. 从机房、区域、机柜和设备详情进入编辑页，原有字段完整回填并可保存修改。
2. 机柜缩容或设备高度变更导致现有放置越界、重叠时，系统拒绝保存且原数据保持不变。
3. 机柜一览默认展示全部机房和全部区域；用户可同时选择多个机房和多个区域。
4. 选择机房后，区域候选项只显示这些机房中的区域；清除筛选后恢复全部机柜。

### AC-008 连续完成日常维护

1. 从某个区域的机柜画布发起新建机柜，表单预选该区域，取消或保存后返回原画布筛选状态。
2. 从机柜详情选择未上架设备，设备列表保留目标机柜上下文，上架页预选该机柜。
3. 移动页同时显示原位置、可用连续 U 位和新占用范围；冲突时指明对应设备且不改变原位置。
4. 从画布或设备详情确认下架后，设备变为未上架，容量立即释放，并返回原任务上下文。

### AC-009 在画布中调整设备布局

1. 用户直接拖动已上架设备时，机柜一览自动进入布局编辑模式。
2. 设备可移动到同一或其他可见机柜，拖动过程中显示完整占用范围，越界或重叠目标不可接受。
3. 连续调整多台设备后，未保存布局只存在于当前编辑会话；选择取消后恢复原布局。
4. 选择“保存调整”后，所有草稿位置在一个事务中生效；任何冲突或写入失败都保留原布局。

### AC-010 调整并保留界面偏好

1. 用户在设置页选择深色外观和蓝色主题色后，应用界面立即更新，无需额外保存。
2. 用户切换到英语后，侧栏、当前页面、表单校验和无障碍标签均使用英语。
3. 重启应用后仍保留上述偏好。
4. 选择“恢复默认设置”后，外观恢复为跟随系统，主题色恢复为中性灰，语言恢复为简体中文。
5. 用户选择 120% 默认画布缩放后，重新进入机柜一览以 120% 显示；临时缩放后点击重置仍回到 120%。
6. 用户分别选择紧凑密度和大字号后，侧栏、页头、列表、表单和设置页立即一致更新；重启后保持选择。
7. 恢复默认设置后，界面密度和字号均恢复为标准档，业务数据不受影响。
8. 用户选择设备资产作为默认启动页后，当前设置页不发生跳转；下次从根地址启动应用时直接打开设备资产。
9. 通过设备详情深链或带机房筛选的机柜一览地址打开应用时，系统保留原地址，不应用默认启动页重定向。

## 12. 已确认产品决策

| 编号 | 问题 | 已确认结论 |
|---|---|---|
| OQ-001 | 设备是否只管理服务器？ | 使用通用设备模型，MVP 提供服务器、交换机、路由器和防火墙。 |
| OQ-002 | 是否只支持 42U？ | 支持常见机柜规格，同时允许设置自定义总 U 数。 |
| OQ-003 | 是否需要机柜背面视图？ | 不需要，仅管理机柜正面 U 位。 |
| OQ-004 | 是否需要拖拽上架？ | 未上架设备仍使用表单；已上架设备允许在画布中拖动调整，同一编辑会话通过“保存调整”统一确认。 |
| OQ-005 | 是否与钉钉资产表同步？ | 不做外部平台同步，保留本地 Excel 导入导出。 |
| OQ-006 | 是否自动检测在线状态？ | 不做自动检测，设备状态由人工维护。 |
| OQ-007 | 是否需要多机共享数据？ | 不做，产品为本机单用户工具。 |
| OQ-008 | 首发平台范围是什么？ | 2026-09-09 调整为 macOS arm64、Windows amd64、Linux amd64/arm64，通过 GitHub Release 分发，不走 Apple 发行。 |
| OQ-009 | 是否提供数据备份、迁移和恢复？ | 不提供；业务数据库固定由应用管理，Excel 导入导出范围不受影响。 |
